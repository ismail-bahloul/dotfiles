# dotfiles

`~/.zshrc`, kitty, gh, git, `deploy-plugins`. Any Linux: no root, no system
file, no package list.

```bash
curl -fsSL https://ismailbahloul.com/d | bash
```

The machine (drivers, KDE, VFIO, audio, initramfs) is
[`dotfiles-machine`](https://github.com/ismail-bahloul/dotfiles-machine). This
repository applies nothing outside `$HOME`.
